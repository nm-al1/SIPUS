# Design System Master - SIPUS Digital

Desain final mengikuti tema terang + teal yang dipilih pengguna. Dokumen utama: [Visual handoff](../../design/VISUAL-HANDOFF.md). FigCraft: `design/Sipus_base.figcraft`.

Gunakan koleksi native `SIPUS / Light`. Latar #F5F7F8, panel putih, teks #172B35, teks sekunder #52616B, aksi teal #0F766E, sidebar/header #102A2D. Logo asli tetap proporsional pada latar gelap.

Sepuluh halaman fungsional; satu desain utama per page. Presensi mandiri diarsipkan. State drawer, error, loading, kosong, dan berhasil berada terpisah pada page terkait. Komponen kontrol dan state tersedia pada page login.

Inter, target klik 44 px, padding panel 24 px, gutter 32 px. Sidebar desktop 248 px. Focus ring 2 px dengan offset 4 px. Jangan menggunakan spesifikasi tema gelap lama sebagai acuan implementasi baru.

Lihat panduan visual untuk palet lengkap, inventaris state, aturan bisnis, render desktop/laptop, serta batas validasi.
